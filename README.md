 Gallery Project

A simple and responsive image gallery built with **React.js** and **Tailwind CSS**, using the **Picsum Photos API** to display images.

Users can browse through the gallery and add or remove images from their **Favourites** by clicking the heart button.

 Live Demo

[Gallery Project](https://gallery-project-delta-plum.vercel.app/)

 GitHub Repository

[View Source Code](https://github.com/ruchitapatil245/Gallery-project)

 Features

 Display images using the **Picsum Photos API**
 Add images to **Favourites**
 Remove images from Favourites
 Navigate through images using **Previous** and **Next** buttons
 Dark-themed user interface
 Responsive design
 Simple and fast React-based interface

 Installation & Setup

 1. Clone the repository

```bash
git clone https://github.com/ruchitapatil245/Gallery-project.git
```

 2. Navigate to the project folder

```bash
cd Gallery-project
```

 3. Install dependencies

```bash
npm install
```

 4. Start the development server

```bash
npm run dev
```

The application will run locally using the Vite development server.

 ❤️ How Favourites Work

Each image has a heart button.

* Clicking the **heart** adds the image to the Favourites section.
* Clicking the heart again removes the image from Favourites.
* The heart icon changes according to the favourite state.

 API

This project uses the **Picsum Photos API** to fetch and display images.

[Picsum Photos](https://picsum.photos/)
